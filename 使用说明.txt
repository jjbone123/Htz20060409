轻量化 AI 驱动校园人才快速筛选系统 —— 使用说明
==================================================

一、系统简介
  本系统以学生在校真实数据为基础，构建五大维度（学业、荣誉、实践、
  科创、综合素质）能力画像，并基于岗位要求进行 AI 智能匹配，为企业
  招聘提供量化、客观、可视化的筛选依据。系统完全在本机运行，数据
  保存在本机，刷新、关机、重启都不会丢失。

二、启动方式
  1. 双击「启动系统.bat」（首次使用请先双击「安装依赖.bat」安装依赖）；
  2. 浏览器会自动打开系统登录页（地址 http://127.0.0.1:8501）；
  3. 默认管理员账号：admin / admin123（登录后建议在系统设置中修改）；
  4. 关闭黑色命令行窗口即停止服务。
  5. 局域网演示（评委手机/电脑访问）：命令行进入系统目录执行
     python server.py --host 0.0.0.0 --port 8501，
     启动信息中会打印「局域网访问地址」，同一 WiFi 下即可打开。

三、七大功能模块
  1. 首页看板：学生总数、岗位数量、已生成画像数、匹配记录统计；
     人才等级分布饼图、各维度平均得分柱状图；新建岗位 / 批量导入 /
     一键 AI 匹配快捷入口。
  2. 学生人才库：按专业、年级、获奖、科创、综合评级多维筛选；
     学生列表姓名/学号脱敏展示；支持批量选中并导出画像摘要；
     支持一键「导出 CSV（当前筛选）」给招聘方（Excel 打开不乱码）。
  3. 岗位管理：维护岗位列表，可新增/编辑/删除岗位；岗位可配置专业要求、
     技能要求与五大能力维度权重（合计须为 100）；新建岗位时可一键套用
     权重模板（技术类/运营类/设计类），再手动微调。
  4. AI 智能匹配（核心）：选择岗位、设置适配分阈值、点击开始匹配；
     按适配分排序展示全部候选人，推荐理由由 DeepSeek 大模型逐批生成
     （配置 Key 时覆盖全部候选人；未配置时自动用本地规则兜底）；
     点击详情查看能力雷达图与各项得分明细。
  5. 报告中心：历史匹配记录列表；支持按岗位筛选、勾选 2-4 条记录
     「对比所选」（阈值/人数/Top5 重合度一目了然）；支持一键下载
     真实 PDF 报告（中文排版）、打印、下载 TXT。
  6. 系统设置（仅管理员）：
     - 指标权重配置：修改五大维度分值占比；
     - 用户权限管理：新增 HR 账号、修改角色与密码、删除账号；
     - 数据导入：Excel/CSV 上传、自动清洗提示；
     - AI 配置：填写 DeepSeek API Key（加密保存在本机，数据库文件中
       不会出现明文）。
  7. 学生端分享：在人才库「查看画像」弹窗中点击「生成分享链接」，
     即可得到二维码；学生用手机扫码可查看自己的脱敏画像
     （24 小时有效，可随时撤销，不会泄露完整姓名学号）。

四、DeepSeek AI 配置（可选但推荐，答辩前务必完成）
  1. 登录 DeepSeek 开放平台申请 API Key（https://platform.deepseek.com）；
  2. 进入「系统设置 → AI 配置」，粘贴 API Key，保存；
  3. 点击「测试连接」确认可用；
  4. 之后 AI 智能匹配会调用大模型实时生成推荐理由（分批调用，覆盖
     全部候选人；单批失败自动回退本地规则，不影响整体结果）。
  注：未配置 Key 时，系统自动使用本地规则生成推荐理由，不影响演示。

五、数据导入说明
  1. 进入「系统设置 → 数据导入」，点击「下载导入模板」；
  2. 按模板格式整理数据（表头含：姓名、学号、专业、年级、获奖情况、
     科创经历、技能标签、学业得分、荣誉得分、实践得分、科创得分、
     综合素质得分），得分范围 0-100；
  3. 选择文件（.xlsx / .csv）点击「开始导入」；
  4. 系统自动清洗：重复学号跳过、缺失得分行跳过、越界得分自动修正，
     并给出清洗报告。
  注：系统内置了 48 条海南高校背景的模拟演示数据，可直接用于演示。

六、数据存储位置（SQLite）
  所有数据保存在本系统目录下的 data/ 文件夹：
    app.db       主数据库（学生/岗位/匹配/账号/设置/分享，SQLite）
    secret.key   加密密钥（API Key 加解密用，请勿删除）
    *.json       旧版 JSON 文件（升级前数据备份，系统启动时已自动
                 导入 app.db，可保留也可删除）
  如需备份，复制整个 data/ 文件夹即可；恢复时放回原位置。
  注意：若删除 secret.key，已保存的 API Key 将无法解密，需重新配置。

七、安全说明
  1. 连续 5 次密码错误，账号锁定 5 分钟；
  2. 登录状态有效期 8 小时，超时需重新登录；
  3. DeepSeek API Key 使用 Fernet 加密存储，数据库文件中不可见明文；
  4. 学生分享链接仅返回脱敏数据，24 小时自动过期，可随时撤销。

八、常见问题
  Q：双击启动后提示找不到 python？
  A：请安装 Python 3（安装时勾选 Add to PATH），或先运行「安装依赖.bat」。
  Q：端口 8501 被占用？
  A：系统会自动尝试 8502-8510 端口，地址会显示在命令行窗口中。
  Q：想在其他电脑/手机上访问？
  A：本系统默认仅本机访问（127.0.0.1）。局域网演示用
     python server.py --host 0.0.0.0；跨公网访问见同目录
     《云端部署指南.md》。
  Q：忘记管理员密码？
  A：删除 data/ 中 app.db 后重启系统，会自动恢复默认账号
     admin/admin123（会同时清空已创建的 HR 账号与全部数据，
     建议先备份 data/ 再操作）。

九、关于当前演示数据
  1. 系统首次启动会自动生成 48 条模拟学生数据与 6 个岗位；
  2. 报告中心已含演示匹配记录，可直接演示「下载 PDF / 多轮对比」；
  3. 自带回归测试（可选）：本机已装 Node.js 时，在系统目录依次执行
     python test_phase1.py / test_phase2.py / test_phase3.py /
     node test_phase2_ui.js / node e2e_test.js，
     可自动完成全部功能的自动化走查（每阶段测试均需全部通过）。

十、答辩演示建议（AI 智能匹配为核心）
  1. 演示前先在「系统设置 → AI 配置」填入 DeepSeek API Key 并测试连接，
     使推荐理由为大模型实时生成；
  2. 进入「AI 智能匹配」选择岗位 → 调节适配分阈值（如 60）→ 点击
     「开始 AI 匹配」，展示候选列表、适配分与 AI 推荐理由；
  3. 点击「查看详情」弹出能力雷达图与各项得分明细；
  4. 再到「报告中心」打开同一次匹配的报告，一键下载 PDF 展示成果；
  5. 加分项：岗位表单现场套用「技术类权重模板」；人才库现场导出 CSV；
     报告中心勾选两条记录「对比所选」展示多轮匹配差异。
